## Proposed minimal build plan

### New pages (5)

1. **`apps/web/src/app/mana/documents/page.tsx` — Document Inbox** → covers (f), feeds (b)
   Table of received files (upload dropzone now; Gmail-ingested later). Columns: filename, source, detected type (commercial invoice / packing list), **auto route badge from filename token** (LAX/SFX/SFO → warehouse; ORD/HNL → direct, F12), parse status (received/parsed/needs-review/committed/failed), reprocess + reassign-route actions. Needs a new `documents` table + storage bucket.

2. **`apps/web/src/app/mana/invoice-review/[id]/page.tsx` — Commercial Invoice Review** → covers (b), (i)
   Opened from the inbox. Left: original file preview; right: **editable** parsed grid with F8 fields (sold-to, date, invoice no, terms, AWB, shipment-from, description, carton #, pieces, lb, unit price, amount, total). Carton-range expander for `5004`, `5005-5009`, comma mixes (F9) with expanded-box chips the user can correct. Match panel against packing-list boxes for the same shipment (F10/F14 — tolerate missing packing list). Every cell overridable, with parsed-vs-corrected shown (F18). Commit → creates/updates lot+boxes (warehouse route) or a direct shipment (direct route).

3. **`apps/web/src/app/mana/direct-shipments/page.tsx` — Direct Shipments + Reinvoice Builder** → covers (a), (c)
   List of ORD/HNL shipments (never enter inventory/allocation, F13). Detail: vendor invoice lines on the left (visible internally only), reinvoice draft on the right — same boxes/items, **new invoice number, editable marked-up rate per line, live margin per line and total** (F15). Explicit "vendor pricing is never included in the customer document" rendering. Push resulting invoice into the existing finance-queue flow. New tables: `shipments` (or orders.type='direct') + `reinvoice_lines` linking vendor line → customer line.

4. **`apps/web/src/app/mana/purchase-orders/page.tsx` — PO Management** → covers (e)
   CRUD grid with F22 fields (customer, order number, order date, items, weight, box number, rate/lb) — requires extending the minimal `purchase_orders` table. Internal-only banner (never sent to vendor, F21). **Excel bulk import** (reuse the vendor-mapping import pattern from `inventory/page.tsx`) and **export** to the QBO-import format they currently pay for (F20). Per-PO status: draft → pushed-to-QBO → converted-to-bill, with `qbo_po_ref` / `qbo_bill_ref`; later direct QBO API push replaces the Excel hop. Note the F23 "billable" investigation belongs here.

5. **`apps/web/src/app/mana/accounts-payable/page.tsx` — Accounts Payable** → covers (d)
   Vendor bills (from settled reconciliations + converted POs + parsed commercial invoices), due date, terms, aging buckets (mirror the `AR_AGING` component in `finance-dashboard/page.tsx`), payment status (unpaid/scheduled/paid/overdue), owner-vs-vendor AP split (F19).
